Completion = completed first rounds / finished first rounds. Without hints uses the same denominator. Duration includes completed and timed-out rounds. Accuracy = correct sorting attempts / all attempts.

The 95% intervals describe uncertainty in each group's completion rate. Interval overlap alone is not a test of the difference between groups. These case files do not measure enjoyment or long-term retention.
